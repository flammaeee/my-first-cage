## 聆途
聆途（LenTour）是一套面向无障碍与复杂场景独立出行的鸿蒙原生多模态智慧助行系统。涉及到相关的硬件设备（如：智能导盲杖，智能墨镜）则是使用OpenHarmony技术。

如果你对本项目感兴趣或者觉得本项目有一些帮助，希望可以给我们一个星星⭐作为支持，非常感谢！
